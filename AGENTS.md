This is a game jam project done in Unity. This doc will detail the high level purpose with the project.

Only files within the root folder (i.e. C:\Users\bille\Documents\TheSillyJamProject) should be modified by agents. 

Generally, agents will write the code and humans will do the prefab or scene setups.

The project is based on the Unity FPSTemplate.

The game will be a boomer style shooter, inspired by Doom. You'll play as Karen Wolfenstein and fight Novo employees, trying to slim you down using Wegovy or Ozempic.

You will fight back by firing cakes at the enemies.

Enemies will be sprite animated in the style of Doom or Wolfenstein.

Weapons will be on-screen sprites, in the style of Doom or Wolfenstein.
